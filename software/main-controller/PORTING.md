# 書き直しの判断：ToraNeko.Mk3 から持ってくるもの、KOGUMA.MkIIl から持ってくるもの

KOGUMA.Mk3.1 は、ToraNeko.Mk3 の `App/` を持ってきて KOGUMA の機体に合わせる形で作ります。
ToraNeko.Mk3 は KOGUMA.MkIIl から「使っていない機能は持ち込まない」と決めて作ったので（ToraNeko.Mk3 の `KOGUMA_PORTING.md`）、**KOGUMA.MkIIl にはあって ToraNeko.Mk3 にはない機能**があります。
このファイルは、それをどうするかを決める表です。コードはここには書きません。

> 見ているコード：KOGUMA.MkIIl `fa64b58`（2026-10-27）、ToraNeko.Mk3 `ecd8e10`（2026-11-04）。新しい変更は毎朝 [../../docs/reference_sync.md](../../docs/reference_sync.md) で見る。

## 方針

- **作り・書き方は ToraNeko.Mk3、値は KOGUMA.MkIIl**（[README.md](README.md) の「書き直しの考え方」）
- ToraNeko.Mk3 で「持ち込まない」と決めた機能でも、**クラシックの大会で KOGUMA が使っているもの**は、もう一度考える（下の B）
- 判断の「案」は Claude の提案。作者に確かめたら「確定」にする。実装はステップの順に 1 つずつ

## A. ToraNeko.Mk3 の `App/` を持ってくるときに直すところ

| 層 | 直すところ |
|---|---|
| `drv/` | ピン・周辺機能（[PIN_REQUIREMENTS.md](PIN_REQUIREMENTS.md) の「ToraNeko.Mk3 との違い」）。タイマーのクロック（90MHz・180MHz）。LED の数（8＋4）。ブザーを足す。スイッチは押すと 0 |
| `config/` | 値を全部 KOGUMA.MkIIl の `Define.h`・`motor.c`・`Wallsensor.c`・`ShortParam.c` から入れ直す（タイヤ 23.42mm、トレッド 55mm、ギア比 1.7073、電池は 4 セル（下限 15.6V、分圧 47k/10k））。制御周期をそろえる（KOGUMA は 1kHz） |
| `ctrl/` | 区画 180mm・柱 12mm。壁までの距離の表（`wall_dist.c`）は KOGUMA.MkIIl の `WallDistance.c` の表から。ゲインは KOGUMA の値を ToraNeko の式に読み替える |
| `maze/` | `MAZE_SIZE` を 16 に。ほかはそのまま使えるはず（PC テストで確かめる） |
| `sys/` | モードの割り当て（下の B の判断のあと、MODES.md で決める） |
| `test/` | 迷路を 16×16 に（KOGUMA.MkIIl の `mazes/` と、ToraNeko.Mk3 の `test/mazes/gen_maze.py`） |

## B. KOGUMA.MkIIl にあって ToraNeko.Mk3 にないもの

## C. ToraNeko.Mk3 にあって KOGUMA.MkIIl にないもの（そのまま持ってくる）

- 層に分けたファイル構成、PC テスト（迷路・モード・出力・Flash・軌道・制御・壁センサ）、CI
- µs のタイマーで制御の処理時間を測る
- 迷路とゴールの位置の Flash への保存（電源を切っても消えない）
- エンコーダの角度の歪みの補正（モード6 No.6）。KOGUMA の磁石がモーターの軸なら、補正の表の考え方を確かめてから
- 速さを 2ms 前のカウントとの差で求める（`ctrl/odometry.c`）
- フェイルセーフの異常の見つけ方（位置・角度のずれ、ぶつかった、壁を押している。決めた時間続いたら止める）
- 壁のない区間で向きを迷路の向きに戻す、柱も使う壁切れ、斜めの直進の補正
- 左右の車輪の速度をログに出す（KOGUMA.MkIIl の `docs/next_robot.md` の 4。ToraNeko.Mk3 の走行ログの列を確かめて、なければ足す）
