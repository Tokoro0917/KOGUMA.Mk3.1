# mechanical/

KOGUMA.Mk3 の機構部品・3D モデル・図面を置きます。**中身は作者に用意してもらいます**（要るときに頼みます）。

## 置き方（ToraNeko.Mk3 と同じ）

```
mechanical/
├── exported/      # 機体全体の STEP など、共有用に書き出したもの
└── jigs/          # 調整用の治具（区画のまん中に置く板、タイヤを浮かせる台など）
```

## ファームウェアで要るもの

| 要るもの | 何に使うか |
|---|---|
| 機体全体の STEP（または寸法の入った図） | センサの位置・向き（壁までの距離の計算）、重心、エンコーダの磁石がモーターの軸かタイヤの軸か |
